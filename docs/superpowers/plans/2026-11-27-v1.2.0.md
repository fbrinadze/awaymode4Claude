# Away Mode v1.2.0 (no-admin workflow route) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A second Teams route that needs no admin: a Power Automate workflow sends branded cards, the user's own small app registration reads replies through Graph; chosen at install next to today's bot route.

**Architecture:** Graph reading moves out of `adapters/teams.ts` into `adapters/graph-chat.ts`, shared by the bot adapter and a new `adapters/workflow.ts` that POSTs Adaptive Cards built by `adapters/card.ts`. `Adapter.send` gains an optional `{project, kind}` so cards get a real header. Sign-in config becomes per route. Routing, delivery, approvals, commands and recap don't change.

**Tech Stack:** Bun + TypeScript (strict), plain `fetch`, Microsoft Graph v1.0, Power Automate "When a Teams webhook request is received", PowerShell 5.1 installer, `az` CLI.

**Spec:** `docs/superpowers/specs/2026-11-27-v1.2.0-design.md`

## Global Constraints

- Zero runtime dependencies; plain `fetch`; no inbound listener; replies by polling only while away.
- No file over 150 lines, no function over 40. Every change test-first with fakes (`test/fake-net.ts`, `test/fake-adapter.ts`); watch it fail before implementing.
- Sender gate unchanged: only `from.user.id === me` is acted on.
- Workflow route scopes exactly `User.Read Chat.Read offline_access`; bot route keeps `User.Read Chat.Read TeamsAppInstallation.ReadWriteSelfForUser offline_access`.
- Graph tools app: client ID `14d82eec-204b-4c2f-b7e8-296a70dab67e`, authority `organizations`, only when `sign_in_app` is `graph-tools`.
- The workflow URL never appears in logs, thrown errors, doctor output, Teams or any file outside the keychain.
- Every new setting goes in plugin.json `userConfig` **and** `mcpServers.away.env`; plugin.json changes ship with a version bump (1.2.0).
- Card header `Claude Code · <tag>` (or `Claude Code` with no project); subtitle `Away Mode · <label>`; footer `ref <8 chars>`.
- `install.ps1` stays PowerShell 5.1 with CRLF line endings.
- Commits end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Never push to main; never merge.

## Review Focus

1. The flow is turned off or deleted (POST returns 4xx): the error names the cause ("the Away Mode workflow didn't accept the message; check it's turned on") and contains no part of the URL → Task 4.
2. An upgrader with bot settings and no `teams_route` set: stays on the bot route with no change → Task 6.
3. Text with `*`, `_`, `<`, `&`, `[link](x)` or a trailing backslash: shown literally in the card (RichTextBlock/TextRun, never TextBlock markdown) → Task 3.
4. Another flow posts a card headed `Claude Code · app` without our ref: no tag learned, never treated as a reply → Task 1.
5. Graph tools token carrying `Directory.ReadWrite.All`: setup warns before pairing, doctor shows ✘ with the extra scopes → Tasks 5 and 7.
